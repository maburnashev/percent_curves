# percent_curves

Проект рассчитывает кривые вмененных процентных ставок по срочным контрактам Московской биржи. Основной сценарий получает данные по фьючерсам, сопоставляет контракты с базовыми активами, учитывает дивиденды по акциям, рассчитывает ставки для разных типов активов, приводит результат к стандартным срокам и сравнивает расчет с данными MOEX.

## Что делает проект

Основная задача проекта - построить таблицу ставок `r` для базовых активов фьючерсного рынка на наборе стандартных сроков:

- `1D`, `1W`, `2W`, `1M`, `2M`, `3M`;
- далее до `10Y` с годовым шагом.

Для акций и индексов расчет старается использовать спот-цену базового актива. Для валют, товаров, ставок и части специальных инструментов используется ближайший фьючерс как условный спот. Для акционных фьючерсов дополнительно учитываются объявленные и исторически ожидаемые дивиденды.

## Python-файлы

### `main.py`

Точка входа в проект. Определяет расчетную дату, создает папку `data_YYYY-MM-DD` и последовательно запускает весь пайплайн:

1. получает исходные данные по фьючерсам;
2. строит маппинг фьючерсов к базовым активам;
3. загружает календарь объявленных дивидендов;
4. рассчитывает вмененные ставки;
5. интерполирует и экстраполирует ставки на стандартные сроки;
6. применяет правила для вечных фьючерсов;
7. сохраняет итоговые файлы и файл проверки.

Если текущая дата приходится на субботу или воскресенье, расчетная дата сдвигается назад до последнего рабочего дня.

### `src/fut_data.py`

Отвечает за загрузку данных по фьючерсам из ISS MOEX.

- `GetFutQuotes(date, meta)` получает XML-таблицы `marketdata` или `securities`.
- `GetFutData(date)` объединяет котировки и параметры контрактов в одну таблицу.

Сохраняет промежуточные файлы с котировками и описанием контрактов.

### `src/mapping.py`

Сопоставляет фьючерсы с базовыми активами и определяет тип актива.

Основные действия:

- получает список серий фьючерсов из ISS MOEX;
- подтягивает справочные таблицы MOEX с кодами базовых активов;
- определяет тип актива: `stock`, `index`, `currency`, `commodity`, `rate`;
- добавляет служебные признаки для дальнейшего расчета.

Результат сохраняется в `mapped_YYYY-MM-DD.csv`.

### `src/calculations.py`

Основной расчетный модуль.

- `MakeCalculations(...)` подготавливает данные, считает дни до экспирации и распределяет инструменты по типам активов.
- `asset_is_spot(...)` рассчитывает ставку через спот-цену акции или индекса.
- `future_is_spot(...)` рассчитывает ставку через ближайший контракт как условный спот.

Для акций модуль учитывает:

- объявленные дивиденды до экспирации фьючерса;
- исторически типичные даты дивидендов;
- средний размер дивиденда;
- дисконтирование дивиденда по ближайшей точке G-кривой;
- теоретическую цену фьючерса и признак, что дивиденд заложен в цену.

Выход модуля - таблица с фактическими сроками до экспирации `t` и рассчитанными ставками `R`.

### `src/extra_data.py`

Содержит функции для загрузки и подготовки дополнительных данных.

- `get_historical_dividends()` собирает исторические дивиденды из файлов в папке `dividends/`.
- `get_ruonia()` рассчитывает годовые и накопленные ставки RUONIA по локальному Excel-файлу.
- `get_dividends()` готовит историческую дивидендную базу и типичные даты выплат.
- `get_currency_rates(trade_date)` получает курсы USD/RUB и EUR/RUB через ISS MOEX.
- `get_avg_dividends()` считает средний дивиденд в рублях по тикеру.
- `get_g_curve(tradedate)` получает G-кривую MOEX.

### `src/dividends.py`

Загружает календарь объявленных дивидендов с Cbonds через Selenium и Chrome.

### `src/output.py`

Формирует финальные таблицы и проверочные результаты.

### `src/date_formatting.py`

Вспомогательные функции для дат и сроков.

## Входные данные

### Данные из внешних источников

Во время запуска проект обращается к:

- ISS MOEX - фьючерсы, параметры контрактов, цены базовых активов, валютные курсы, G-кривая и контрольные ставки;
- справочным страницам MOEX - маппинг и типы базовых активов;
- Cbonds - календарь объявленных дивидендов. Для загрузки календаря Cbonds нужен установленный Google Chrome и доступная авторизация Cbonds. Логин и пароль лучше передавать через локальный .env файл.

### Локальные данные

Папка `dividends/` содержит локальные Excel-файлы, которые используются для исторической дивидендной базы.

- `shares_mapping.xlsx` - список ISIN/тикеров, для которых подтягиваются исторические дивиденды;
- `RC_F11_01_2010_T05_08_2026.xlsx` - данные RUONIA;
- файлы вида `RU....xlsx` - исторические дивиденды по отдельным бумагам;
- `shares_with_futures.xlsx` - агрегированный файл исторических дивидендов, который может пересоздаваться при запуске.
- в дальнейшем процесс сбора исторических дивидендов с cbonds можно автоматизировать благодаря проделанному маппингу акций с id cbonds

## Последовательность выполнения расчета

1. `main.py` выбирает расчетную дату и создает папку результатов.
2. `GetFutData()` загружает котировки и описания фьючерсов из ISS MOEX.
3. `MapSecurities()` связывает фьючерсные коды с базовыми активами и типами активов.
4. `build()` из `src/dividends.py` получает таблицу объявленных дивидендов Cbonds.
5. `MakeCalculations()` готовит даты, сроки до экспирации и рассчитывает ставки:
   - для акций и индексов - через спот-цену базового актива;
   - для остальных активов - через ближайший контракт как условный спот;
   - для акций - с поправкой на дивиденды, если они попадают в срок жизни фьючерса.
6. `BuildTable()` переводит фактические точки кривой к стандартным срокам.
7. `ApplyPerpetualRates()` подставляет ставки для вечных фьючерсов (кроме SP500F, QQQF) из связанных обычных контрактов.
8. `Compare()` загружает контрольные ставки MOEX и формирует Excel-файл сравнения.

## Общая логика расчета вмененной ставки:
Если тип базового актива != акция или индекс, используем расчет по принципу ближайший фьючерс=спот

Если фьючерс QQQF или SP500F, используем расчет по принципу ближайший фьючерс=спот

Если тип базового актива == акция или индекс, получаем котировки базовых активов и получаем ставки.

Те фьючерсы, что после расчетов ставок имеют ставки nan, отправляются на пересчет в логику для != акции или индексу

Вечные фьючерсы (кроме QQQF, SP500F) берут ставки у своих невечных аналогов. По QQQF и SP500F так сделать нельзя, потому что нет обычных фьючерсов. Ставка по ним ~то же, что фандинг, но в % годовых.
